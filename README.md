# texclip

一个轻量级 Windows 剪贴板工具，将 LaTeX 数学公式分隔符转换为 Markdown 常用的美元符号格式。

使用 Rust 编写，可由 [Quicker](https://getquicker.net/) 等快捷工具直接调用，无需常驻后台。

## 功能特性

- **公式转换**：将 `\(...\)` 转换为 `$...$`，将 `\[...\]` 转换为 `$$...$$`。
- **成对匹配**：只转换正确配对的公式分隔符，不修改未匹配的标记。
- **嵌套保护**：遇到嵌套分隔符时，仅替换最外层的一对。
- **代码保护**：跳过 Markdown 围栏代码块和行内代码。
- **行内限制**：行内公式只允许在同一行内匹配，块级公式支持跨行。
- **直接操作剪贴板**：读取、转换并写回，无需临时文件。
- **轻量运行**：原生 Windows 可执行文件，无需 Python 或 .NET 运行时。

## 转换示例

### 行内公式

转换前：

```text
质能方程为 \(E=mc^2\)。
```

转换后：

```text
质能方程为 $E=mc^2$。
```

### 块级公式

转换前：

```text
\[
E = \frac{1}{2}mv^2
\]
```

转换后：

```text
$$
E = \frac{1}{2}mv^2
$$
```

### 嵌套分隔符

仅替换最外层的一对：

```text
输入：\[start \[nested\] end\]
输出：$$start \[nested\] end$$
```

### 代码保护

Markdown 行内代码及围栏代码块中的公式分隔符不会被替换。

例如：

````text
`\(...\)` 不会被转换。

```latex
\[
E = mc^2
\]
```
````

## 安装与编译

需要安装 [Rust](https://www.rust-lang.org/tools/install)。

克隆项目并编译：

```powershell
git clone <repository-url>
cd texclip
cargo build --release
```

编译完成后，可执行文件位于：

```text
target\release\texclip.exe
```

也可以运行单元测试：

```powershell
cargo test
```

## 使用方法

1. 复制包含 LaTeX 公式的文本。
2. 运行 `texclip.exe`。
3. 程序自动读取剪贴板、转换公式并写回。
4. 使用 `Ctrl + V` 粘贴转换后的文本。

如果没有需要转换的公式，剪贴板文本保持不变。

### 配合 Quicker 使用

推荐通过 [Quicker](https://getquicker.net/) 实现一键转换：

1. 在 Quicker 中新建动作。
2. 添加「运行程序」步骤。
3. 指定 `texclip.exe` 的绝对路径。
4. 保存动作，并根据需要设置快捷键。

此后只需复制文本并触发 Quicker 动作，即可完成转换。

## 转换规则

| 输入 | 输出 | 说明 |
|---|---|---|
| `\(x+y\)` | `$x+y$` | 行内公式 |
| `\[x+y\]` | `$$x+y$$` | 块级公式 |
| `\[` + 换行 + `x\]` | `$$` + 换行 + `x$$` | 允许块级公式跨行 |
| `\(` + 换行 + `x\)` | 不转换 | 行内公式不能跨行 |
| `\(x` | 不转换 | 缺少结束标记 |
| `x\)` | 不转换 | 缺少开始标记 |
| `\[a \[b\] c\]` | `$$a \[b\] c$$` | 仅替换外层 |
| `` `\(x\)` `` | 不转换 | Markdown 行内代码 |

## 注意事项

- 本工具只处理纯文本剪贴板内容，不保留 HTML 等富文本格式。
- 只转换 LaTeX 公式分隔符，不修改公式内部的数学表达式。
- 对于非标准 Markdown 结构或复杂的混合嵌套，转换结果不保证符合完整的 Markdown 或 LaTeX 语法。
- 程序不会自动粘贴转换结果，需要用户自行粘贴。

## 技术实现

- **语言**：Rust
- **剪贴板库**：[arboard](https://crates.io/crates/arboard)
- **文本处理**：标准库与状态机解析
- **目标平台**：Windows
- **运行方式**：单次执行，无后台常驻进程
